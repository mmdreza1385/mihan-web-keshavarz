# میهن وب کشاورز 🌾

اپلیکیشن فروشگاهی کشاورزی — آفلاین + پیام‌رسانی ابری

## نصب
1. فایل `mihan-web-keshavarz-2.1.0.apk` را دانلود کنید
2. روی فایل بزنید و نصب را تأیید کنید (در صورت نیاز، «نصب از منابع ناشناس» را فعال کنید)
3. همین! بدون اینترنت هم کامل کار می‌کند؛ با اینترنت، پیام‌رسانی ابری فعال می‌شود

- نسخه: ۲.۱.۰ (versionCode 22)
- 🌐 **مثل تلگرام:** هر کسی روی هر دستگاهی (اندروید/iOS/دسکتاپ) ثبت‌نام کند، در فهرست مخاطبین شما با نشان دستگاهش (📱/🍎/💻) ظاهر می‌شود و می‌توانید مستقیم پیام بدهید
- 🔒 متن پیام‌ها با رمز AES-GCM (کلید مبتنی بر شماره‌های دو طرف) از سرویس ntfy.sh رله می‌شود؛ بدون اینترنت، پیام صف می‌شود و بعداً خودکار می‌رود
- 🪪 کارت گفتگو: کارت خودتان را از «مخاطبین → 🪪 کارت من» بفرستید؛ با چسباندن لینک در کادر جستجو، کارت شما آفلاین روی دستگاه مقابل ثبت می‌شود
- 🔄 همگام‌سازی گفتگو با فایل برای انتقال کامل پیام‌ها (و عکس‌ها) بین دو گوشی — کاملاً آفلاین
- 💬 پیام‌رسان: چت دوطرفه، عکس و کلیپ، جستجوی پیام‌ها و مخاطبین، گروه و کانال، حذف پیام مثل واتساپ
- 🛡 فایروال داخلی: فقط هوش مصنوعی، هوا، فونت‌ها و ntfy.sh به اینترنت وصل می‌شوند؛ بقیه مسیرها بسته است
- 🆕 ورود فقط با شماره تلفن + کد پیامکی ۴ رقمی از «میهن وب»
